# Riyadh Metro Network 

An interactive Power BI dashboard analyzing Riyadh Metro stations across different metro lines and station types.

## Project Overview

This project provides an interactive analysis of the Riyadh Metro network, focusing on station distribution, station types, geographic locations, and station sequence.

## Key Features

- Analysis of 94 Riyadh Metro stations across 6 metro lines
- Interactive filtering by metro line
- KPI cards for total stations and metro lines
- Analysis of station types
- Geographic visualization of station locations using latitude and longitude
- Station sequence analysis
- Dynamic DAX measures
- Data transformation and preparation using Power Query

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Visualization
- Geospatial Analysis

## Data

The dataset contains information about Riyadh Metro stations, including:

- Station name
- Metro line
- Station type
- Station sequence
- Geographic coordinates

## Data Source

The dataset used in this project was obtained from the Royal Commission for Riyadh City (RCRC) Open Data Portal.

Source: [Riyadh Metro Train Routes 2025](https://opendata.rcrc.gov.sa/explore/assets/metro-lines-in-riyadh-2024/)

## Dashboard

The dashboard provides an interactive view of the Riyadh Metro network, allowing users to explore stations based on metro line and station type.
